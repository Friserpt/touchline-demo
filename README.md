# Touchline · Demonstração jogável

## Jogar sem depender de GitHub Pages

Descarrega [Touchline-pronto.zip](https://github.com/Friserpt/touchline-demo/raw/refs/heads/main/Touchline-pronto.zip), extrai a pasta e abre Touchline.html. O ZIP contém apenas o jogo e instruções. Alternativa: [Touchline.html](https://github.com/Friserpt/touchline-demo/raw/refs/heads/main/Touchline.html).

Abre o ficheiro guardado em Chrome ou Edge e escolhe **Jogar carreira local**. O JavaScript, o CSS e o SQLite estão incluídos no HTML. Não é necessário instalar Node nem iniciar um servidor. Esta é uma carreira individual, sem contas nem mercado entre utilizadores.

Em **Finanças**, usa **Exportar carreira** para preservar o progresso. Mantém o ficheiro na mesma pasta para facilitar a recuperação da gravação do navegador. A compatibilidade de armazenamento em ficheiros locais depende do navegador; os testes deste ambiente verificam o pacote numa origem HTTP local, pois a política administrativa bloqueia file://.

## Site

Quando a publicação GitHub Pages concluir, o site estará em https://friserpt.github.io/touchline-demo/ . Este link não prova que a publicação já terminou.

A edição inclui carreiras históricas opcionais de 2024/25 com clubes e jogadores reais, calendários portugueses/ingleses e gravações independentes. Não são plantéis atuais de 2026. Perfis ingleses incluem estatísticas históricas. A carteira regista os TC e há aceleradores de obras e treino individual. Os pacotes mostram preços propostos; não existe checkout ou cobrança real no site estático. Retratos e siglas são ilustrações; não se incluíram fotografias nem emblemas oficiais. A vista 3D opcional está disponível em Competições; mantém-se 2D para dispositivos sem WebGL. Os pacotes de teste foram revistos para 0,99/2,99/5,99 €, com os TC anteriores preservados. A v0.10 acrescenta o Gabinete: planos semanais, equipa técnica com salários e efeitos, observação com relatórios por jornada, contratação pelo perfil, jogadores seguidos, ambição da época e caixa de entrada. A v0.9 inclui treino diário em Plantel, evolução visível em todas as abas, obras com imagens por nível, comparação de jogadores e retratos originais gerados/ilustrados (16 personagens fictícias e 16 figuras do futebol, identificadas como IA; não são fotografias oficiais). A atualização da cache conserva as carreiras. A edição inclui movimento contextual com condução, receção e interceções, leitura tática opcional em 2D/3D, estádio animado, decisões ao intervalo, progressão, cartões de jogadores, instalações, academia, planos individuais, objetivos da direção, equipamentos, patrocínios e aceleradores com TC de jogo. Não processa pagamentos reais; a carreira local não é uma carteira de moeda paga.
