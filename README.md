# Touchline · Demonstração jogável

## Jogar sem depender de GitHub Pages

Descarrega [Touchline-pronto.zip](https://github.com/Friserpt/touchline-demo/raw/refs/heads/main/Touchline-pronto.zip), extrai a pasta e abre Touchline.html. O ZIP contém apenas o jogo e instruções. Alternativa: [Touchline.html](https://github.com/Friserpt/touchline-demo/raw/refs/heads/main/Touchline.html).

Abre o ficheiro guardado em Chrome ou Edge e escolhe **Jogar carreira local**. O JavaScript, o CSS e o SQLite estão incluídos no HTML. Não é necessário instalar Node nem iniciar um servidor. Esta é uma carreira individual, sem contas nem mercado entre utilizadores.

Em **Finanças**, usa **Exportar carreira** para preservar o progresso. Mantém o ficheiro na mesma pasta para facilitar a recuperação da gravação do navegador. A compatibilidade de armazenamento em ficheiros locais depende do navegador; os testes deste ambiente verificam o pacote numa origem HTTP local, pois a política administrativa bloqueia file://.

## Site
